## 🚀 How to Use

### **Option 1: Open the Live Application** (Recommended)
1. Click: **https://arqamxjay.github.io/World-Intelligence-Command-Centre/**
2. No installation required
3. Start exploring intelligence data immediately

### **Option 2: Clone & Run Locally**
```bash
# Clone the repository
git clone https://github.com/arqamxjay/World-Intelligence-Command-Centre.git

# Navigate to the directory
cd World-Intelligence-Command-Centre

# Start a local server
python3 -m http.server 8000

# Open in browser
# http://localhost:8000/global-intel-hub.html
```

### **Option 3: Fork & Deploy Your Own**
1. Fork: **https://github.com/arqamxjay/World-Intelligence-Command-Centre**
2. Enable GitHub Pages in settings
3. Your live site will be available at: `https://{your-username}.github.io/World-Intelligence-Command-Centre/`
