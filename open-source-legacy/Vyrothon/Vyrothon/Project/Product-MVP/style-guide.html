Colour System

Dark-mode-first. Two brand primaries (indigo + cyan), semantic state colours, and a neutral ramp on a blue-tinted black base. All foreground/background combinations meet WCAG AA (4.5:1 contrast).

02
Typography

Two fonts. Syne (800 weight) for all display and heading text — its geometric, architectural quality creates a distinctive editorial identity. DM Sans for all body copy — optically balanced at reading sizes. JetBrains Mono for code, keyboard shortcuts, and metadata.

03
Components

All interactive components used across the Creatix auth, onboarding, and dashboard flows. Documented with state rules and annotation.

Buttons
Primary (#5B5BF5): single highest-priority action per screen. Secondary: supporting actions. Ghost: navigation-style actions, low visual weight. Danger: destructive operations only, never default. Never two Primary buttons on one screen. Disabled: 40% opacity + cursor:not-allowed.
Inputs — States
Default
Focus
Error
Please enter a valid email.
Success
Looks good!
Height: 44px · Border-radius: 14px (--r-md) · Focus ring: 3px solid rgba(primary, 0.35). Error shown on blur only. Labels always above input. Placeholder: --text-3.
Cards
Base card
Creation mode tiles, intent cards, recent items
Elevated
Modals, dropdowns, popovers
Accent
AI prompt bars, featured elements
Border-radius: 20px (--r-lg). 1px solid border at --border opacity. Hover: translateY(-2px) + border-color change. Mode cards add a 2px top-border in the mode's accent colour. Never use box-shadow as the sole hover affordance.
Badges
✨ Primary ✓ Success ⚠ Warning ✕ Danger
Background: 15% opacity of semantic colour. Text: full semantic colour. Always border-radius: 100px. For status and labels only — never for interactive actions. New/Beta mode labels use the primary badge.
